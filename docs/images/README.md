# Photos and videos

Real-world photos of the build and the tests, used by the README and the docs.

| File | Shows |
|---|---|
| `field_overview.jpg` | The whole field from an angle: floor, walls, towers, camera mast |
| `field_top.jpg` | The field from the camera's point of view |
| `car_front.jpg`, `car_side.jpg`, `car_top.jpg` | The car from three sides, marker visible |
| `car_inside.jpg` | The electronics and wiring |
| `camera_mount.jpg` | The Pi 5 and the camera on the mast |
| `control_center.png` | A screenshot of the Control Center page |
| `pi_preview.png` | The Pi preview with the coordinate grid on the tile seams |
| `test_*.jpg` / `.gif` | Moments from the tests in [testing](../testing.md) |

Keep each image under about 1 MB (resize to about 1600 px wide), so the repository stays quick
to clone. Long videos are better linked from YouTube or a GitHub release than committed.
